Project Workflow

How Smartpocket AI works

User → Frontend (user information) → Backend (receives & processes) → Gemini AI (generates recommendation) → Recommendation logic → Frontend (result) → Output.

01

Gemini AI Initialization

Google Cloud + Gemini 1.5 Flash Pro API access is configured, with prompts fine-tuned for budget interpretation and multimodal (text + image) understanding.

02

Core Functionality Development

A modular backend accepts budgets and optional images, then routes them to Home, Party, or Jewelry planning logic in gemini_utils.py.

03

FastAPI Backend Integration

FastAPI bridges the frontend and Gemini AI layer with routes like /generate-home, /generate-party, and /generate-jewelry, plus JWT-secured auth.

04

UI Development & Testing

A responsive Jinja2/HTML/CSS/JS frontend renders structured recommendations, tested end-to-end across real-world budgets and scenarios.

Architecture Overview

Core technologies under the hood

Smartpocket AI is an intelligent, modular platform that integrates a lightweight FastAPI backend with Google's Gemini 1.5 Flash Pro to process text, numbers, and images.

Gemini 1.5 Flash Pro

Multimodal AI model for understanding budget context, analyzing outfit images, and generating structured JSON recommendations.

FastAPI Backend

Manages routing, JWT-based sessions, and communication between the UI and the Gemini AI layer.

Third-Party Platform APIs

Sources product & service data from Amazon, Flipkart, IKEA, Swiggy, Zomato, OYO, Tanishq & more.

HTML/CSS/JS Frontend

Jinja2-templated, responsive interface for input collection and AI-driven output display.

Backend Routes (FastAPI)

/generate-home/generate-party/generate-jewelry /register/login/logout/token /session-info/session-data/recommendations-details /history/startup

This front-end demo mirrors those routes using local, in-browser session storage — so you can explore the full experience without a live backend deployment.
